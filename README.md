โครงการนี้มุ่งพัฒนาแอปพลิเคชันเพื่อส่งเสริมสุขภาพ โดยใช้เทคโนโลยีการวิเคราะห์รูปร่างจากภาพดิจิทัลและการตรวจจับจุดสำคัญของร่างกาย (Pose Detection) เพื่อประเมินสัดส่วนและสภาพร่างกายของผู้ใช้ ข้อมูลที่ได้จะถูกนำมาประมวลผลเพื่อสร้างโปรแกรมออกกำลังกายและโภชนาการแบบเฉพาะบุคคล พร้อมระบบจัดเก็บข้อมูลผู้ใช้และติดตามความก้าวหน้าในรูปแบบกราฟและสถิติ ช่วยให้ผู้ใช้สามารถดูแลสุขภาพได้อย่างเป็นระบบ มีประสิทธิภาพ และสอดคล้องกับเป้าหมายด้านสุขภาพของแต่ละบุคคล
